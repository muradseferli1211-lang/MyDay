# My Day

Dark Android productivity app for planning study, tracking expenses, recording water, and keeping food notes.

## Tech
- Kotlin
- Jetpack Compose
- Jetpack Glance AppWidget
- Material 3

## Build
Open this folder in Android Studio, let Gradle sync, then:
Build > Build App Bundle(s) / APK(s) > Build APK(s)

The app is designed for a real Android project rather than GitHub Pages.

## Widget
After installing the APK, long-press the Redmi home screen and add the **My Day** widget.

## Important
The current version is a solid starter implementation. Before treating it as a finished personal app, add persistent storage, notifications, editable lessons/expenses/food entries, real weekly navigation, and widget refresh from the same stored data.
